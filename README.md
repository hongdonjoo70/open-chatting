# Flask 기반 실시간 Open Chatting

IP 기반 1인 1접속 제어, 공지사항 및 귓속말(DM), 대화 기록 검색(탐색창), DB 영구 저장 기능을 갖춘 실시간 오픈 채팅 웹 애플리케이션입니다.

---

## 📁 프로젝트 디렉토리 구조

```
open-chatting/

├── socket_events.py           # SocketIO 실시간 이벤트 (메시지, 공지, DM, 닉네임)
├── requirements.txt           # 프로젝트 의존성 목록
├── test_chat.py               # 기능 통합 테스트 스크립트
├── views/
│   ├── __init__.py            # Blueprint 초기화
│   ├── auth.py                # 접속/로그인 화면 뷰 (IP 중복 체크)
│   └── chat.py                # 채팅방 뷰 및 탐색창 검색/닉네임 API
├── templates/
│   ├── base.html              # Bootstrap 5 기반 공통 레이아웃
│   ├── login.html             # 접속/로그인 화면
│   └── chat.html              # 채팅창 (공지사항, 대화목록, 입력창, 접속자목록, 탐색창)
└── static/
    ├── css/
    │   └── style.css          # 부트스트랩 보완용 최소화된 CSS
```

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 서버 실행
```bash
python app.py
```

### 3. 브라우저 접속
- 로컬 접속: `http://localhost:4000` 또는 `http://127.0.0.1:4000`
- 동일 네트워크의 다른 기기/PC에서 접속: `http://<서버IP>:4000`

## ✨ 요구사항 반영 기능

1. **IP 기반 단일 접속 제어 (1 IP = 1 Session)**:
   - 클라이언트의 접속 IP를 자동 인식합니다.
   - 동일한 IP로 여러 개의 창이나 탭을 열면 접속이 거부(차단)됩니다.
   - 창을 닫으면(`beforeunload` 및 Socket.IO disconnect) 사용자의 접속이 자동으로 해제됩니다.

2. **닉네임 자동 설정 및 영구 유지**:
   - 최초 접속 시 닉네임은 접속한 `IP 주소`로 자동 부여됩니다.
   - 상단 네비게이션의 **[이름 변경]** 버튼을 통해 언제든지 닉네임을 변경할 수 있습니다.
   - 변경된 닉네임은 SQLite 데이터베이스(`User` 테이블)에 저장되어 재접속 시에도 계속 유지됩니다.

3. **메시지 전송 옵션**:
   - **전체에게 전송**: 모든 접속자에게 공개 메시지를 전달합니다.
   - **공지사항으로 전송**: 상단 공지사항 배너 및 대화창에 강조된 스타일로 즉시 반영됩니다.
   - **특정 사용자에게 전송 (귓속말/DM)**: 현재 접속 중인 사용자 중 원하는 대상을 선택하여 1:1 비밀 메시지를 전송합니다 (발신자와 수신자만 열람 가능).

4. **채팅창 UI 구성**:
   - **공지사항 창 & 삭제**: 상단에 가장 최근 공지사항이 표시되며, [삭제] 버튼을 통해 언제든 공지를 해제할 수 있습니다.
   - **실시간 대화창**: 전체 메시지, 공지사항, 귓속말, 입장/퇴장 시스템 메시지가 구분되어 표시됩니다.
   - **현재 접속자 목록 창**: 우측 사이드바에 실시간 접속자 목록 및 인원 수가 표시되며, 귓속말 바로보내기 버튼을 지원합니다.
   - **Bootstrap 5 활용**: CSS를 최소화하고 Bootstrap 5 컴포넌트를 사용하여 반응형 디자인을 적용했습니다.

5. **여러 줄(Multi-line) 입력 지원**:
   - `Ctrl + Enter`: 메시지가 전송되지 않고 다음 줄로 줄바꿈(개행)됩니다.
   - `Enter`: 메시지를 즉시 전송합니다.
   - 입력된 여러 줄의 개행 스타일이 대화창에 그대로 보존되어 출력됩니다.

6. **그림(이미지) 및 파일 첨부 / 다운로드**:
   - 메시지 입력창 좌측의 클립(<i class="bi bi-paperclip"></i>) 버튼으로 사진 및 파일을 선택할 수 있습니다.
   - **이미지 파일**: 대화창에 썸네일 미리보기로 출력되며 클릭 시 원본 이미지를 새 탭에서 확인할 수 있습니다.
   - **일반 파일**: 파일명, 파일 크기 및 [다운로드] 버튼 카드로 출력되어 간편하게 내려받을 수 있습니다.

7. **탐색창 (채팅 내용 검색)**:
   - 상단의 **[채팅 탐색창]** 버튼을 클릭하면 별도의 독립된 창(모달)이 열립니다.
   - 키워드 검색 및 메시지 유형 필터링(전체, 공지사항, 귓속말)을 지원하며, 검색어 하이라이트 및 첨부파일 여부를 제공합니다.
   - 데이터베이스(`Message` 테이블)에 저장된 이전 대화 기록 중 권한이 있는 메시지만 안전하게 탐색할 수 있습니다.

8. **실시간 화면/윈도우 공유 (WebRTC)**:
   - 상단 헤더의 **[화면 공유]** 버튼을 누르면 브라우저의 화면 선택 다이얼로그가 표시되며, **특정 애플리케이션 창(Window)**, 전체 화면, 또는 브라우저 탭을 선택하여 다른 접속자들에게 초당 30fps 고화질로 실시간 공유할 수 있습니다.
   - 화면 공유 중에도 실시간 채팅 및 파일 전송이 동시에 가능하며, 전체화면 버튼을 제공합니다.
   - 상단의 **[공유 취소]** 버튼 또는 브라우저의 공유 중지 툴바를 클릭하면, 실시간 화면 영역이 닫히고 **기존 채팅 모드로 원활하게 복귀**합니다.

9. **채팅 내용 전체 삭제(초기화)**:
   - 실시간 대화창 상단 헤더의 **[대화 삭제]** 버튼(<i class="bi bi-trash3"></i>)을 클릭하면, 확인 팝업 후 데이터베이스(`Message` 테이블)에 저장된 모든 대화 내용이 영구 삭제됩니다.
   - 모든 참가자의 대화창이 실시간으로 비워지며 초기화 알림 메시지가 출력됩니다.
